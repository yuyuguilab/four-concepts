# 四个概念，四种类型：智能、人类智能、人工智能、通用人工智能的层次、边界与转译协议

*余玉桂 · 余玉桂战略研究室 · they4897@gmail.com*

本文是同一研究纲领的第四篇概念工作（前三篇：理论论文《拟合实践，而非作品：AGI 人本拟合论》、方法论论文《拟合实践：前沿模型训练的数据方法论》、概念解绑论文《两个不同的目标：机器之心与人工智能的概念解绑》）。

## 一句话

四个词不在一条阶梯上：智能问度量，人类智能问常模，人工智能问造物判据，通用人工智能问参照系。

## 三项主张

1. **类型论**：四个词是四种概念类型——能力概念（智能）、样本概念（人类智能）、造物概念（人工智能）、参照系概念（通用人工智能）。每类“定义完成”的形态不同；流行的“专用—通用—超级”阶梯是把四类概念串在一条线上的叙事装置。
2. **分层论**：每个概念内部分本体层（它是什么）、认识层（什么证据支持某系统具有它）、方法层（用什么程序检测）。定义之争的慢性病是三种非法滑动：操作主义（测量冒充定义）、部分谬误（机制冒充能力定位）、判据升格（造物判据冒充概念内容）。
3. **转译协议**：工程观察（电路、特征、梯度、基准得分）到概念命题的转译表，每行附生效条件；附四种非法转译目录（定位式、整体错置式、升格式、普遍化式）。

## 与前作的分工

- 理论论文（AGI 人本拟合论）：本文引用其“通用性是关系属性”作为参照系概念的现成理论形式；
- 概念解绑论文：其“功能智能”成为造物概念的判据；“评估的不对称”在本文分层论中获得解释；
- 方法论论文：其披露审计成为方法层正确形态的范例（转译条件随行）。
